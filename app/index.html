Build UL Mod Buddy Data

Grant access to your 7 Days To Die install folder (the one containing Mods\UndeadLegacy and Data) to (re)build the local dataset from it, entirely in your browser. Nothing is ever uploaded -- no server is involved at all, and no mod files are copied anywhere.

Your browser doesn't support the File System Access API this needs. Chrome and Edge support it out of the box; Firefox and Safari currently don't. Brave ships the same engine as Chrome but disables this API by default -- enable it at brave://flags/#file-system-access-api and relaunch, or just use Chrome/Edge. See the README for the alternative local-Python setup.
